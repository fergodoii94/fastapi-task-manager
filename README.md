# Task Management API 🚀
A high-performance REST API built with FastAPI for managing daily tasks.
- **Features:** Full CRUD operations, Pydantic data validation, Automatic Swagger Documentation.
- **Tech Stack:** Python 3.x, FastAPI, Pydantic.
- **How to run:** `pip install fastapi uvicorn` -> `uvicorn main:app --reload`
